# 인생 정산소 — 국민연금 정산기

영상에 쓴 계산을 그대로 공개합니다.
숫자를 옮겨 적은 게 아니라, 공개된 제도 값을 넣고 처음부터 돌린 결과입니다.

**👉 [웹 계산기 열기](https://appleejh.github.io)** — 조건을 바꾸면 수익비가 바로 따라 움직입니다.

---

## 왜 공개하나

영상에서 이렇게 말했습니다.

> "마음에 안 드는 가정이 있으면 직접 바꿔보실 수 있게 계산 코드도 공개합니다."

숫자는 가정 하나로 뒤집힙니다. 결론만 보여주고 가정을 감추면, 그 결론은 믿을 이유가 없습니다.
그래서 계산식과 가정을 전부 여기 둡니다.

---

## 핵심: 할인율 하나가 결론을 바꾼다

1990년생 남성, 27세 취업, 33년 납입, 가입기간 평균 월소득 320만원 기준입니다.
**같은 사람, 같은 제도인데 실질 할인율만 바꾸면 이렇게 됩니다.**

| 실질 할인율 | 수익비 | |
|---|---|---|
| 0.0% | 1.92배 | |
| **0.55%** | **1.62배** | 국민연금연구원 공표치와 일치 |
| 1.0% | 1.41배 | |
| 2.0% | 1.04배 | 사실상 본전 |
| 3.0% | 0.76배 | **손해** |

기본값 0.55%는 제가 고른 값이 아닙니다.
국민연금연구원이 공표한 1990년생 남성 수익비 1.62배를 재현하도록 **거꾸로 계산해 맞춘 값**입니다.
모델이 공표치를 맞힌 게 아니라, 맞추도록 맞춰놓은 것입니다.

할인율에 정답은 없습니다. 기관마다 다르게 씁니다.
**어떤 기사에 나오는 수익비든 이 과정을 거쳐 나온 숫자입니다.**

---

## 계산 방법

### 납입

```
그 해 납입액 = 월소득 × (1 + 실질임금상승률)^경과년수 × 12 × 보험료율
```

보험료율은 2026년부터 매년 0.5%p씩 올라 13%에서 멈춥니다(2025년 개혁 반영).
**사업장 부담분을 포함한 전액 기준**입니다. 내 통장에서 빠진 절반만 세면 수익비는 두 배가 됩니다.
공식 추계도 전액으로 계산하므로 여기서도 전액으로 갑니다.

### 급여

국민연금 산식을 그대로 씁니다.

```
기본연금액(연) = 상수 × (A + B) × (1 + 0.05 × n / 12)

  A  전체 가입자 평균소득월액
  B  본인 가입기간 평균소득월액
  n  20년 초과 가입월수
  상수  1.2 × (소득대체율 / 0.40)
```

**(A + B)에서 A가 절반을 차지하는 게 핵심입니다.**
소득이 낮을수록 B가 작아 급여 대비 본인 기여가 줄고, 그래서 수익비가 올라갑니다.
이 재분배를 빼고 계산하면 저소득층 수익비가 실제보다 크게 과소평가됩니다.

### 현재가치

낸 돈은 30·40대에, 받는 돈은 70대에 발생합니다. 사이에 30년이 넘는 시차가 있습니다.
두 흐름을 같은 시점(가입 시작)으로 당겨서 비교합니다.

```
현재가치 계수 = (1 + 할인율)^-(나이 - 가입나이)
수익비 = 수령액 현재가치 합 / 납입액 현재가치 합
```

## 가정

| 항목 | 값 |
|---|---|
| 물가상승률 | 2.0% |
| 명목 임금상승률 | 3.1% |
| A값 (전체 가입자 평균소득) | 310만원 |
| 취업 나이 | 27세 |
| 65세 기대여명 | 남 21.5년 / 여 26.5년 |
| 보험료율 | 9% → 13% (2026~2033 단계 인상) |
| 소득대체율 | 43% |
| 실질 할인율 | 0.55% (공표치 재현값) |

## 직접 돌려보기

웹 계산기로 충분하지만, 코드로 돌려보고 싶으시면:

```bash
npm i -g tsx
npx tsx model/report.ts
```

출력에 수익비, 평생 납입·수령액, 손익분기 나이, 할인율 민감도, 소득별 수익비가 나옵니다.
가정을 바꾸려면 `model/pension.ts`의 `ASSUMPTIONS`를 고치면 됩니다.
